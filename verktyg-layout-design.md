# Färg och typografi
  
   
## Färgpaletter:

Coolors: https://coolors.co

Realtime Colors (testa palett på layout) https://www.realtimecolors.com

Adobe Color (färghjul med regler, bra för att förstå *varför*): https://color.adobe.com

Color Hunt (färdiga, trendiga paletter): https://colorhunt.co

Happy Hues (paletter i sammanhang): https://www.happyhues.co

Khroma (lär sig dina färgval): https://www.khroma.co

UI Colors (skala 50-900 från en färg): https://uicolors.app

    
Radix Colors (tillgängliga skalor, ljust/mörkt): https://www.radix-ui.com/colors

Eva Design System (skalor och semantiska färger, teman): https://colors.eva.design

---

## Typsnitt:

Google Fonts (gratis fonter, sortera på popularitet): https://fonts.google.com

Fontpair (färdiga rubrik- och brödtextpar): https://www.fontpair.co

Fontshare (gratis fonter, ofta snyggare än Google): https://www.fontshare.com

Modern Font Stacks (systemfont-stackar, ingen nedladdning, hållbarhet): https://modernfontstacks.com

Fonts In Use (vilka typsnitt riktiga sajter använder): https://fontsinuse.com

Type Scale (räkna ut en typskala): https://typescale.com

Variable Fonts (en fil, många vikter): https://v-fonts.com

WhatFontIs (identifiera typsnitt från en bild): https://www.whatfontis.com
